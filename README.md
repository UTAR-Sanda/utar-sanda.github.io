# UTAR 散打基础训练手册

UTAR 武术散打队新人基础训练手册的网站版。

## 链接

| 用途 | 链接 |
| --- | --- |
| 手册网站（给所有人看） | https://utar-sanda.github.io |
| 内容表（改手册内容，只有获授权的人能编辑） | https://docs.google.com/spreadsheets/d/1w9bWDu2FM8i-XJFyfmhYTSlq3KtzrPb7XYtlxfzEwA4/edit |
| 维护与交接指南（PDF） | [maintenance-guide.pdf](maintenance-guide.pdf) |

需要编辑内容表的话，打开链接后按「请求访问权限」，等负责人批准。

## 文件

- `index.html`：网页本身。
- `data.json`：手册内容的快照。网页先显示这份，再去读 Google Sheet 的最新内容（`index.html` 里的 `PUB` 设定）。
- `utar-sanda-progress.xlsx`：新人进度记录表（空白 Excel 模板），网站上可以直接下载。
- `maintenance-guide.pdf`：维护与交接指南（怎么改内容、加动作、发布设定、换届交接），网站上可以直接下载。

内容不要在这里改，请改内容表。
